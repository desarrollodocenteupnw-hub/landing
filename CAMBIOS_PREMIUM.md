# Evolución visual premium del Portal DGDD

Actualización: noviembre de 2026

## Alcance aplicado

La línea visual premium aprobada fue extendida a las superficies principales del portal:

- Inicio
- Nuestra Dirección
- Procesos
- Inducción
- Formación
- Acompañamiento
- Evaluación
- Reconocimiento
- Recursos
- Agenda
- Innovación
- Resultados
- Detalle de eventos
- Página 404
- Header y footer globales

## Sistema visual

- Uso de paleta institucional Wiener como base.
- Jerarquía editorial y mayor presencia fotográfica.
- Héroes internos consistentes mediante un componente reutilizable.
- Tarjetas de procesos con identidad diferenciada dentro de un mismo sistema.
- Secciones de "Qué encontrarás" para orientar la navegación en cada proceso.
- Mayor profundidad mediante fondos suaves, radios amplios, sombras discretas y geometrías de marca.
- Footer simplificado para evitar duplicar navegación.

## Gantt / Agenda

En esta etapa NO se modificaron las reglas, fechas ni datos del Gantt. El componente existente se mantiene y solo recibe el nuevo tratamiento visual. La actualización a 2027-I y 2027-II se realizará en la siguiente etapa.

## Despliegue

El proyecto conserva la configuración de Netlify con Node 24. La vista previa multipágina incluida en la entrega es una revisión visual independiente; el código fuente productivo continúa siendo el proyecto Astro.

## Gantt multiperiodo 2026-2027

- Periodos disponibles: 2026-I, 2026-II, 2027-I y 2027-II.
- El selector del componente Agenda toma automaticamente los periodos publicados.
- 2027-I replica la secuencia del periodo equivalente 2026-I desplazada 52 semanas.
- 2027-II replica la secuencia del periodo equivalente 2026-II desplazada 52 semanas.
- Las actividades 2027 se identifican como proyeccion hasta su validacion final.
- Vista de referencia: docs/Gantt_DGDD_Multiperiodo_2026_2027.html.
